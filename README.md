## 🌟 Overview

The **Social Media Management Application** is a full-stack web platform that enables users to manage multiple social media accounts such as **Facebook** and **Instagram** in one place.  
It allows easy scheduling of posts, interaction with followers, and access to insightful analytics — all through an intuitive and modern interface.

---

## 🧠 Key Features

✅ **Multi-account integration** – Connect Facebook and Instagram accounts via OAuth  
✅ **Post scheduling** – Plan and publish posts automatically  
✅ **Interactive content calendar** – Visualize and manage upcoming content  
✅ **Inbox system** – Manage messages and comments in real-time  
✅ **Analytics dashboard** – Track engagement, impressions, and growth  
✅ **Responsive UI** – Built with React, Tailwind CSS, and Framer Motion  

---

## 🧩 Tech Stack

| Category | Technology |

## 🚀 Installation & Setup

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/rahmafakhfakh/social-media-management.git

# Navigate into the project directory
cd social-media-management

# Install dependencies
npm install

# Start the backend server
npm run server

# Start the frontend
npm run dev

```
